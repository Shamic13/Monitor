# 💻 PC Hardware Monitor (Python + Arduino)

Аппаратно-программный комплекс для независимого мониторинга телеметрии ПК (температуры, потребляемая мощность, загрузка ОЗУ и VRAM) с выводом на внешний дисплей и автоматическим логированием в Excel.

## 🚀 Особенности проекта
* **Прямой доступ к ядру (Ring 0):** Считывание точных данных с датчиков материнской платы, CPU и GPU через библиотеку `LibreHardwareMonitor`.
* **Авто-обход UAC:** Скрипт `run.bat` автоматически запрашивает права Администратора для корректной работы драйвера.
* **Без мерцания (Flicker-free):** Реализован алгоритм стирания артефактов на LCD дисплее невидимыми пробелами вместо полной очистки экрана.
* **Защита от потери пакетов:** Строгая синхронизация UART потока по стартовому маркеру `<`.
* **Аналитическое логирование:** Аппаратная кнопка `SELECT` на устройстве запускает автоматическую запись логов телеметрии и генерацию графика в `.xlsx` формате средствами Python.

## 🛠 Технологический стек
* **Серверная часть (ПК):** Python 3, `pythonnet`, `psutil`, `pyserial`, `openpyxl`.
* **Клиентская часть:** Arduino Uno R3, модуль LCD Keypad Shield (LCD 1602).
* **Интерфейс связи:** UART (COM-порт).

## ⚙️ Установка и запуск
1. Подключите Arduino с установленным LCD Keypad Shield к USB порту.
2. Загрузите прошивку `.ino` в микроконтроллер через Arduino IDE.
3. Установите зависимости Python:
